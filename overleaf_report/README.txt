GRID PULSE OVERLEAF REPORT

1. Upload the ZIP file to Overleaf as a new project.
2. Keep pdfLaTeX as the compiler.
3. Set main.tex as the main document if Overleaf does not select it automatically.
4. Click Recompile.

The project is self-contained. The figure is stored in figures/ and all links are
already included in main.tex.
